# Skills do projeto

Skills versionadas para orientar agentes que trabalham neste repositório.

## Impeccable
Origem: https://github.com/pbakaus/impeccable · Apache-2.0 · versão consultada: 4.10.0

- .agents/skills/impeccable/SKILL.md
- Referências incluídas: reference/new-work.md, reference/new-work-world.md, reference/craft-floor.md

Use em criação, revisão e refinamento de interfaces. A skill original faz referência a scripts e playbooks adicionais do repositório upstream; estes não foram copiados nesta instalação inicial. Não execute comandos da skill sem confirmar que os scripts existem localmente.

## Superpowers
Origem: https://github.com/obra/superpowers · MIT

Skills incluídas:
- using-superpowers
- brainstorming
- writing-plans
- test-driven-development
- verification-before-completion

Este é um conjunto inicial de skills centrais, não uma instalação integral do projeto Superpowers. Skills que dependem de subagentes, worktrees ou ferramentas específicas devem ser instaladas quando o ambiente suportar esses recursos.

## Ordem recomendada
1. Consultar using-superpowers e identificar skills aplicáveis.
2. Para trabalho novo, usar brainstorming e registrar o design aprovado.
3. Para implementação com múltiplas etapas, usar writing-plans.
4. Para comportamento de software, aplicar test-driven-development.
5. Antes de declarar conclusão, aplicar verification-before-completion.
6. Para UI, combinar com Impeccable e com as regras do produto em PRODUCT.md.

Não afirmar que uma skill foi executada sem realmente ler e seguir seu conteúdo.
